# PaxAutocraticaHelper（暗星铁律 士兵管理 + 快捷命令）v0.5.0

《Pax Autocratica》（暗星铁律）BepInEx 6 插件。

**设计原则**：游戏内面板只做士兵管理；其他功能全部走快捷键（减少误触、界面清爽）。
所有数值/开关可在 BepInEx 管理器里表单化编辑。

## 功能

### 士兵管理（F1 面板）
- 士兵列表（点击选中，属性自动同步到输入框）
- 属性编辑：等级 / 经验 / 体力 / 饱食 / 心情 / 支持 / 恐惧 / 金币 / 工资 / 10 种工作速度
- 「应用属性」(F3) 写入游戏
- 「复制当前士兵」(F2)：以当前士兵为模板生成一名新兵并复制全部属性
- 自动同步：游戏中查看的士兵自动载入面板

### 快捷键（面板外功能全部用快捷键）

| 快捷键 | 功能 |
|---|---|
| F1 | 开关士兵管理面板 |
| F2 | 复制当前士兵 |
| F3 | 应用属性到当前士兵 |
| Ctrl+1 / 2 / 3 / 4 | 时间 2x / 5x / 10x / 1x |
| Ctrl+5 | 完成所有研究 |
| Ctrl+6 | 自动保存 |
| Ctrl+7 | God Mode（需配置开启） |
| Ctrl+8 | Daddy Mode（需配置开启） |
| Ctrl+9 | 免费制造 开（需配置开启） |
| Ctrl+0 | 智能自动分配 |

### 自动行为
- 全局人员自动分配（间隔可配，默认 60 秒）
- 士兵轮询同步（间隔可配，默认 0.5 秒）
- 机器人强化：读取到机器人（种族 459）数据时自动拉满属性（数值可配置）

## 配置项（BepInEx/config/com.hhewww.paxautocraticahelper.cfg）

| 节 | 键 | 默认 | 说明 |
|---|---|---|---|
| 通用 | 启用便利面板 | true | F1 面板总开关 |
| 通用 | 显示作弊功能 | false | 开启后 Ctrl+7/8/9 生效（God/Daddy/免费制造） |
| 面板 | 界面缩放 / 位置X / 位置Y / 宽度 / 高度 | 2 / 20 / 60 / 330 / 470 | 面板布局 |
| 面板 | 显示延迟(秒) | 8 | 进游戏多久后可显示面板 |
| 自动行为 | 自动分配间隔(秒) | 60 | 0 = 关闭 |
| 自动行为 | 士兵轮询间隔(秒) | 0.5 | 面板同步频率 |
| 自动行为 | 士兵列表刷新间隔(秒) | 2 | 列表冷却 |
| 机器人强化 | 启用 / 种族ID / 体力 / 饱食 / 心情 / 支持 / 恐惧 / 最低等级 | true / 459 / 100×4 / 0 / 100 | 机器人属性强化 |

## 构建与部署

```powershell
.\build.ps1
```

部署到 `BepInEx/plugins/PaxAutocraticaHelper/`（自动备份旧 dll 为 .bak）。重启游戏生效。
