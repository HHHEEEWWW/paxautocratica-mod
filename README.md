# PaxAutocraticaHelper（暗星铁律 士兵管理 + 快捷命令）v0.5.7

《Pax Autocratica》（暗星铁律）BepInEx 6 插件。

> **开发者请看**：[开发手册 DEVELOPMENT.md](./DEVELOPMENT.md)（架构 / 模块 / 工具链 / 游戏内部 API / 已知坑 / 进行中工作）。

**设计原则**：游戏内面板只做士兵管理；其他功能全部走快捷键（减少误触、界面清爽）。
所有数值/开关可在 BepInEx 管理器里表单化编辑。

## 功能

### 士兵管理（F1 面板）
- 士兵列表（点击选中，属性自动同步到输入框）
- 属性编辑：等级 / 经验 / 体力 / 饱食 / 心情 / 支持 / 恐惧 / 金币 / 工资 / 10 种工作速度
- 「应用属性」(F3) 写入游戏
- 「复制当前士兵」(F2)：以当前士兵为模板生成一名新兵并复制全部属性（**只继承正面战斗类特质**：攻击速度/移动速度/射击伤害/暴击/生命护盾/换弹切枪等，剔除负面与非战斗特质，如煽动者/躁动/体弱/种族限定/忠诚波动）
- 自动同步：游戏中查看的士兵自动载入面板。**v0.5.7 强化**：在游戏「士兵管理」页点击任意单位（或打开详情弹窗），MOD 面板立即载入该单位属性；F1 打开面板时也会立刻拉取当前在游戏里看中的单位——**不用去 MOD UI 列表里翻名字**。

### 快捷键（面板外功能全部用快捷键）

| 快捷键 | 功能 |
|---|---|
| F1 | 开关士兵管理面板 |
| Ctrl+1 | 时间倍速**循环切换**：1x → 2x → 5x → 10x → 1x … |
| Ctrl+2 | 完成所有研究 |
| Ctrl+3 | 设置**所有单位**恐惧为 0 |
| Ctrl+7 | God Mode（需「显示作弊功能」开启） |
| Ctrl+8 | Daddy Mode（需「显示作弊功能」开启） |

> **复制士兵 / 应用属性无快捷键**（v0.5.3 起），只能通过面板按钮操作，防止误触。
> v0.5.7 起移除：Ctrl+4 时间 1x（并入 Ctrl+1 循环）、Ctrl+5 完成研究（改 Ctrl+2）、Ctrl+6 自动保存（游戏系统自带）、Ctrl+9 免费制造（触发游戏 VFX 报错，见变更历史）、Ctrl+0 智能自动分配（游戏系统自带）。

### 自动行为
- 士兵轮询同步（间隔可配，默认 0.5 秒）

## 配置项（BepInEx/config/com.hhewww.paxautocraticahelper.cfg）

| 节 | 键 | 默认 | 说明 |
|---|---|---|---|
| 通用 | 启用便利面板 | true | F1 面板总开关 |
| 通用 | 显示作弊功能 | false | 开启后 Ctrl+7/8 生效（God/Daddy） |
| 面板 | 界面缩放 / 位置X / 位置Y / 宽度 / 高度 | 2 / 20 / 60 / 330 / 470 | 面板布局 |
| 面板 | 显示延迟(秒) | 8 | 进游戏多久后可显示面板 |
| 自动行为 | 士兵轮询间隔(秒) | 0.5 | 面板同步频率 |
| 自动行为 | 士兵列表刷新间隔(秒) | 2 | 列表冷却 |

## 构建与部署

```powershell
.\build.ps1
```

部署到 `BepInEx/plugins/PaxAutocraticaHelper/`（自动备份旧 dll 为 .bak）。重启游戏生效。
升级后若配置面板出现已删除的旧条目（如机器人相关），删除 cfg 文件后重启游戏即可重新生成。

## 变更历史

- **v0.5.7**：快捷键重排——Ctrl+1 时间倍速循环切换（1↔2↔5↔10x）、Ctrl+2 完成所有研究、Ctrl+3 全体恐惧归零；**移除**自动保存（系统自带）、智能自动分配（系统自带，含 60 秒定时与 Ctrl+0）、Ctrl+9 免费制造（触发游戏 VFX 超容量报错：`VFXPlaySystem` 对 `DROP_VFX_GREEN` 常量特效每帧重播且缺可见性守卫，属游戏 bug）；士兵面板**点选即同步**强化（游戏点谁面板跟谁，F1 打开即拉取当前选中，不用翻名字）
- **v0.5.6**：士兵列表修复——过滤已死亡/已流放 NPC（实测 65 个已死士兵不再残留）；列表数据源加只读字典兜底路径；**面板标题栏可拖动**（按住顶部"士兵管理面板"拖动到任意位置，自动保存配置）；复制源诊断日志
- **v0.5.5**：复制士兵新增**特质过滤**——只保留正面战斗类特质（攻击速度/移动速度/射击伤害/暴击/全伤害/生命护盾/换弹切枪/弹匣等 24 类模式），剔除负面与非战斗特质（煽动者/躁动/体弱/种族限定/忠诚波动等）；特质判定依据配置表 `NpcAffix.m_localKey`（特质名），配置表未加载时降级保留原特质（不破坏复制）；支持游戏 8/15 更新后的新架构（NPC 特质运行时生成，存档 `afx=null`）
- **v0.5.4**：面板补上「采摘速度」输入框（原 19 个属性中仅此一个漏画，导致无法编辑）；士兵列表实时刷新（复制新兵后立即出现在列表、F1 打开面板立即刷新，不等 2 秒冷却）
- **v0.5.3**：修复复制士兵不继承属性（改为 AddPeople 后同步捕获新兵，Postfix 仅兜底）；删除 F2/F3 快捷键（复制/应用属性只走面板按钮，防误触）；面板背景改为不透明（不再透出游戏画面）
- **v0.5.2**：修复 3 个 bug（Ctrl+7/8/9 作弊快捷键绕过「显示作弊功能」开关；Exec 全局限频吞掉连按快捷键；复制士兵竞态——误把自然生成 NPC 当新兵）；构建链适配管理器隔离模式（csproj 引用 + build.ps1 部署自动指向档案目录）
- **v0.5.1**：移除机器人强化功能（含配置项）；清理旧 cfg 残留键
- **v0.5.0**：面板精简为纯士兵管理；机器人生成功能移除；快捷键体系固定（Ctrl+7/8/9 受「显示作弊功能」开关控制）
- **v0.4.0**：全面配置化重构（配置项 30+，可在管理器表单编辑）；命令执行 MethodInfo 缓存；输入改用 InputLegacyModule
