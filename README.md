# PaxAutocraticaHelper（暗星铁律 便利面板）重构版

《Pax Autocratica》（暗星铁律）BepInEx 6 插件：游戏内便利面板 + 士兵管理 + 快捷命令。

基于 v0.3.0 反编译重构：**功能全部保留，数值/开关/间隔全面配置化**（可在 BepInEx 管理器里表单化编辑），作弊功能默认隐藏。

## 功能

- **便利面板**（F1 开关）：士兵列表/选择/复制（F2）/属性编辑 20+ 项（等级、经验、体力、饱食、心情、支持、恐惧、金币、工资、10 种工作速度）（F3 应用）
- **快捷键**：Ctrl+1~4 时间倍率、Ctrl+5 完成研究、Ctrl+6 自动保存、Ctrl+7/8 God/Daddy、Ctrl+9 免费制造、Ctrl+0 智能分配、Ctrl+` 生成机器人
- **常用命令**：时间加速 1/2/5/10x、建筑效率 x1/x5/x10、完成所有研究、自动保存
- **机器人强化**：新生成/读取的机器人自动满属性 + 高等级（数值可配置）
- **自动行为**：全局人员自动分配（间隔可配）、士兵面板自动同步

## 配置项（BepInEx/config/com.hhewww.paxautocraticahelper.cfg）

| 节 | 键 | 默认 | 说明 |
|---|---|---|---|
| 通用 | 启用便利面板 | true | F1 开关面板 |
| 通用 | 显示作弊功能 | **false** | 面板中显示作弊按钮（God/Daddy/停止AI/免费制造/解锁平民/可拆建筑） |
| 面板 | 界面缩放 | 2 | 面板缩放倍数 |
| 面板 | 位置 X/Y、宽度、高度 | 20/60/330/470 | 面板布局 |
| 面板 | 显示延迟(秒) | 8 | 进游戏多久后可显示 |
| 自动行为 | 自动分配间隔(秒) | 60 | 0=关闭 |
| 自动行为 | 士兵轮询间隔(秒) | 0.5 | 面板同步频率 |
| 自动行为 | 士兵列表刷新间隔(秒) | 2 | 列表冷却 |
| 自动行为 | 机器人生成数量 | 5 | Ctrl+` 数量 |
| 机器人强化 | 启用 / 种族ID / 体力 / 饱食 / 心情 / 支持 / 恐惧 / 最低等级 | true / 459 / 100×4 / 0 / 100 | 机器人属性强化 |
| 作弊 | 各作弊按钮开关 | false | 显示对应作弊按钮 |

## 构建与部署

```powershell
.\build.ps1
```

部署到 `BepInEx/plugins/PaxAutocraticaHelper/`（自动备份旧 dll 为 .bak）。重启游戏生效。

## 与 v0.3.0 的差异

- 全部魔法数值配置化（机器人种族 459、强化属性、间隔、数量）
- 作弊功能默认隐藏，配置开启
- 命令执行 MethodInfo 缓存（原为每次全量反射）
- 按键检测改用 InputLegacyModule（原 InputSystem 在 interop 缺失）
- 帧驱动改用 MonoBehaviour.Update（原挂载未知 Harmony 帧钩子）
- 面板布局（位置/尺寸/缩放）可配置
